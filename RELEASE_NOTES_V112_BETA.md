# NoticeFlow Receiver v1.1.2 Beta Material 3

This is a new, non-destructive official Beta release for package `app.receiver`. Previous Alpha and FCM releases remain available unchanged.

## What is included

The Receiver keeps the approved Material 3 interface and live behavior: guided onboarding, Firebase Email/Password authentication, editable device naming, authenticated Receiver registration, notification permission handling, FCM receipt, and local notice inbox history. The Beta carries the rebuilt official signed APK/AAB for clean installation after removal of any legacy debug-signed Receiver build.

## Verification

The Receiver package is `app.receiver`, version code `5`, version `1.1.2-beta-material3`, with Android 8.0+ support. The APK verifies using APK Signature Scheme v2 and the official Receiver certificate fingerprint `E0:18:38:EB:3F:58:B2:D3:C9:0A:7F:E7:18:45:1E:E5:E8:0D:D8:40`.

If an older debug-signed Receiver is installed, uninstall that old Receiver before installing this official Beta. This clears only that device’s local Receiver setup and inbox, not backend device records or Sender data.
